# Native dependency notices

This directory contains upstream license texts and notices for the native build. `rust/dependencies.json` records locked Cargo dependencies, including optional and platform-specific packages; their presence in this inventory does not mean every package is linked into the Windows executable. Per-package license/copyright files are copied from the corresponding registry source distributions. Regenerate them with `native/collect-notices.ps1` after changing Cargo.lock.

Qt 6.8.3 is dynamically linked. `qt/*.spdx.json` are the SDK's upstream software bills of materials, containing package copyright, source URLs, license expressions and extracted non-standard license texts. The adjacent license texts come from the pinned [Qt Base v6.8.3 LICENSES directory](https://github.com/qt/qtbase/tree/v6.8.3/LICENSES). The Qt source used for this build is available from [qtbase](https://github.com/qt/qtbase/tree/v6.8.3), [qtdeclarative](https://github.com/qt/qtdeclarative/tree/v6.8.3) and [qtsvg](https://github.com/qt/qtsvg/tree/v6.8.3). Qt is used under the LGPLv3 options identified in those packages. Ordinary DLL/plugin files can be replaced in the installed directory or portable cache; the launcher does not hash-lock Qt libraries.

`libjpeg-turbo` contains the official 3.2.1 project's license and IJG notice. The direct TurboJPEG DLL is distributed alongside the app. Its [corresponding source and release](https://github.com/libjpeg-turbo/libjpeg-turbo/releases/tag/3.2.1) are public. Cloudflared 2026.9.3 is distributed under Apache-2.0; its [source release](https://github.com/cloudflare/cloudflared/tree/2026.9.3) and license are available upstream. The Visual C++ Desktop runtime is distributed from the Visual Studio redistributable directory under Microsoft's applicable redistributable terms. Inno Setup is a build-time installer compiler.

OpenDesk's own source is MIT-licensed. Qt and dependency licenses retain their own terms. No proprietary AnyDesk code or assets are included.
